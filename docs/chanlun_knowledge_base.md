## 一、理论体系全景

### 1.1 三大系统
缠论主张用三个独立系统相互验证：
1. **技术分析系统** — 走势图形几何化分析（核心）
2. **基本面系统** — 比价关系、板块轮动
3. **比价关系系统** — 不同品种间的相对估值

### 1.2 形态学 + 动力学
- **形态学**（静态/结构）：分型、笔、线段、中枢、走势类型
- **动力学**（动态/力度）：背驰、盘整背驰、MACD 辅助、区间套

### 1.3 自相似结构
走势在不同级别上呈现自相似的分形结构：
- 年线 → 月线 → 周线 → 日线 → 30分钟 → 5分钟 → 1分钟
- 任何级别都可以递归分解为次级别走势类型的连接

## 二、核心概念词典

### 2.1 分型 (Fractal)
| 类型 | 定义 |
|------|------|
| 顶分型 | 3K线中，中间高点和低点均为最高 |
| 底分型 | 3K线中，中间低点和高点均为最低 |

中继分型：反向力度不够，不构成笔的起终点。

### 2.2 笔 (Bi / Stroke)
- 相邻顶底之间的连接
- 顶底之间至少 1 根独立 K 线
- 方向交替：向上笔与向下笔交替出现

### 2.3 线段 (Line Segment)
- 至少 3 笔，前 3 笔必须有重叠
- 特征序列：与线段方向相反的笔序列
- 用特征序列分型判断线段结束（两种情况）

### 2.4 中枢 (Zhongshu / Pivot / Hub)
- 至少三个连续次级别走势类型的重叠部分
- 区间公式：`ZG = min(g1,g2,g3)`, `ZD = max(d1,d2,d3)`
- 中枢是技术分析的核心

### 2.5 走势类型
| 类型 | 包含中枢数 | 方向 |
|------|-----------|------|
| 盘整 | 1 个 | 无 |
| 上涨趋势 | ≥2 个 | 向上 |
| 下跌趋势 | ≥2 个 | 向下 |

### 2.6 级别
- 递归定义：1分钟线段 → 1分钟中枢 → 1分钟走势 → 5分钟线段 → ...
- 显微镜比喻：大级别 vs 小级别 K 线图只是精度不同
- 操作级别由资金量和性格决定

## 三、买卖点体系

### 3.1 三类买卖点（对称）
| 类型 | 买点 | 卖点 |
|------|------|------|
| 第一类 | 下跌趋势背驰，最后中枢下方最低 | 上涨趋势背驰，最后中枢上方最高 |
| 第二类 | 一买后次级别回抽不创新低 | 一卖后次级别反弹不创新高 |
| 第三类 | 次级别离开中枢后回抽不破 ZG | 次级别离开中枢后回抽不破 ZD |

### 3.2 买卖点完备性定理
市场任何上涨与下跌，都必然从三类买卖点的某一类开始及结束。只有这三类买卖点。

### 3.3 操作策略
1. 大级别买点介入，次级别一卖减仓，次级别一买回补（T+0 短差）
2. 中枢上方减仓位，中枢下方加仓位（中枢震荡差价）
3. 中枢上移时满仓不动
4. 三买后未出现趋势则盘整高点出

## 四、背驰体系

### 4.1 背驰 vs 盘整背驰
| | 背驰 | 盘整背驰 |
|---|------|----------|
| 发生位置 | 趋势（两中枢后） | 盘整中 |
| 比较对象 | 两个中枢连接段 | 同向两段 |
| 操作意义 | 趋势反转信号 | 短差机会 |
| MACD表现 | 明显力度衰减 | 可能不明显 |

### 4.2 MACD 标准形态（上涨趋势）
```
阶段1: 黄白线上穿 0 轴，形成第一中枢
阶段2: 价格突破中枢，黄白线快速拉起（力度最大）
阶段3: 形成第二中枢，黄白线回抽 0 轴附近  
阶段4: c段背驰：黄白线不创新高 / 柱子面积缩小
```

### 4.3 三种辅助判断方法
1. **柱子面积比较**：c 段 MACD 柱面积 < b 段
2. **黄白线高低**：c 段白线 < b 段白线
3. **柱子伸长高度**：c 段柱高 < b 段柱高

### 4.4 小级别背驰引发大级别转折
- 大级别背驰段中的小级别背驰意义重大
- 非背驰段中的小级别背驰只是短差机会

## 五、区间套

### 5.1 定义
对于大级别背驰段，用次级别背驰精确定位转折点，逐级递归。

### 5.2 示例（上证 2007年6月 1分钟图）
```
第一重：65-72 相对于 55-60 背驰
第二重：69-72 相对于 65-66 背驰  
第三重：71-72 相对于 69-70 背驰
第四重：71 内部出现分笔背驰
→ 四重区间套精确定位 72 为卖点
```

## 六、中枢相关定理

### 6.1 中枢延伸
- 等价于任何 Zn 的 [dn, gn] 与 [ZD, ZG] 有重叠
- 9 段延伸升级为更高级别中枢

### 6.2 中枢新生（趋势延续）
- 上涨：后 DD > 前 GG
- 下跌：后 GG < 前 DD

### 6.3 中枢级别扩展
- 后 ZG < 前 ZD 且 后 GG ≥ 前 DD（产生更高级别中枢）

### 6.4 走势延续定理
在更高级别中枢产生前，当前级别走势类型将延续。

## 七、操作层面要点

### 7.1 仓位管理
- 操作级别中枢上移 → 满仓
- 中枢震荡 → 上方减仓、下方加仓
- 出现三卖 → 不做差价，等新中枢

### 7.2 选股优先级
1. 三买后中枢新生的股票（趋势延续）
2. 二买 + 三买重合的股票（最强力度）
3. 第一类买点的股票（转折介入）
4. 中枢震荡的股票（做差价）

### 7.3 不参与的情况
- 操作级别及以上级别的下跌
- 超过操作级别的盘整
- 三卖已出现的品种（等新中枢形成后再说）

### 7.4 资金管理要点
> "一笔无风险、可以抵挡突然变盘压力的自有资金"

- 必须保留机动资金
- 组合中留一只"老实巴交"的股票保证随时变现
- 阻击不要变成庄家

## 十、常见问题 FAQ

**Q: 分型被包含关系合并掉了怎么办？**
A: 说明该分型不成立。合并后重新判断。

**Q: 一笔需要多少根K线？**
A: 至少 5 根（顶 + 底 + 中间至少 1 根独立K线，每个分型 3 根，但顶底的 K 线不可共用）。

**Q: 缺口怎么处理？**
A: 顺向缺口（顺着线段方向）包含在一笔中；逆向缺口可当独立线段处理。

**Q: 线段什么时候真正结束？**
A: 特征序列出现分型 + 确认。两种情况：第一二元素无缺口（直接确认），有缺口（需反向特征序列分型确认）。
